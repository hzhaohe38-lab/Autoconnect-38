# 社区互动指南

本项目处于起步阶段，欢迎同学、室友和校园网用户试用并反馈。每一次 Star、Watch 和 Issue 都会帮助项目适配更多校区与运营商。

## 1. 试用前准备

1. 在 GitHub 仓库页面点击 **Star**，方便以后找到项目；
2. 点击 **Watch** → **Custom** → 勾选 **Issues**，及时收到讨论通知；
3. 按 README 的“快速开始”运行一次 `ruijie-login.ps1 -Once`；
4. 记录你的操作系统、运营商、网络类型（有线 / 无线）和运行结果。

## 2. 提交反馈 Issue

进入 [Issues](https://github.com/hzhaohe38-lab/Autoconnect-38/issues) → **New issue**，选择模板。如果没有合适模板，可以直接复制下面的内容：

```markdown
### 试用环境
- 学校 / 校区：
- 操作系统：Windows ___
- PowerShell 版本：
- 运营商：移动 / 联通 / 电信 / 校园网
- 网络类型：有线 / 无线

### 运行结果
- [ ] 一次登录成功
- [ ] 需要重试后成功
- [ ] 未能登录

### 日志（请先打码学号和密码）
```text
粘贴 ruijie.log 中的相关片段
```

### 其他说明
```

## 3. 反馈时的隐私要求

- **不要**上传含学号、密码、Cookie 的完整日志或截图；
- 账号可用 `2025******` 代替，IP 可只保留网段；
- 如果误传了敏感信息，请立即删除评论并修改校园网密码。

## 4. 维护者响应

- 工作日 48 小时内回复 Issue；
- `bug` 标签优先处理，`enhancement` 标签进入版本计划；
- 欢迎同学认领 `good first issue`，维护者会提供复现步骤和修改建议；
- 合并后的贡献者会记录在 Release Notes 中。

## 5. 邀请同学参与

可以把下面这段话发到班级群或宿舍群：

> 我做了一个校园网自动登录工具 Autoconnect-38，支持 Windows 双击运行，第一次输入学号、密码和运营商后就能后台自动认证。项目是 Apache 2.0 开源的，欢迎帮忙点个 Star、Watch，或者按 Issue 模板反馈你所在校区的认证情况。遇到问题直接把脱敏日志贴到 Issue 里，我会尽快回复。

## 6. 行为规范

参与讨论即表示同意遵守 [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)。请尊重不同校区的网络环境和技术方案，对事不对人。
